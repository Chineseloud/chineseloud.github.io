# Free Fire Hub

A simple site for Free Fire players who want to improve fast. 
We focus on sensitivity settings, play styles, and character combos that actually work in ranked and CS Ranked.

## **What this site is about**
Free Fire Hub collects and tests:
- **Sensitivity Settings**: DPI, camera, scope, and ADS values for different phones
- **Play Styles**: Rusher, Sniper, IGL, Passive, Headshot-focused setups
- **Characters**: Best skill combos, ability synergies, and counters for the current meta
- **Guides**: Tips that are updated with each OB patch

No cheats. No mods. Just settings and strategies that help you aim better and win more fights.

## **Features**
- **Sensitivity Profiles**: Copy presets for Android and iOS, low-end to high-end devices
- **Character Builder**: See which 4-skill combos work best together right now
- **Play Style Guides**: Learn movement, peeking, drag headshot, and positioning
- **Patch Notes**: Quick breakdown of what changed in the latest update

## **How to use**
1. Pick your device type and play style
2. Copy the sensitivity settings
3. Test in Training Grounds, then tweak by 5-10 points
4. Check the character page for a combo that matches your role
